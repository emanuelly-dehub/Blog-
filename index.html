SOBRE O PROJETO

Interfaces que aproximam pessoas e tecnologia.

O ConectaWeb é um projeto desenvolvido para demonstrar conceitos de criação de páginas web.

O site utiliza HTML, CSS e JavaScript separados em arquivos independentes, além de recursos como responsividade, classes, temas, efeitos e sombras.
