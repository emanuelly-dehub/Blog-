# 🤠 Estilo Country

Blog sobre moda country, tendências, looks e dicas de estilo.

## 📌 Sobre o projeto

O Estilo Country é um blog desenvolvido para apresentar
conteúdos relacionados à moda country de uma maneira moderna,
elegante e responsiva.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 📂 Estrutura

blog-moda-country/
│
├── index.html
├── style.css
├── script.js
└── README.md

## ✨ Funcionalidades

- Menu responsivo
- Navegação por seções
- Cards de tendências
- Modal com informações adicionais
- Área de inspiração de looks
- Formulário de newsletter
- Animações ao rolar a página
- Design responsivo para celular, tablet e computador

## 🚀 Como executar

1. Baixe ou copie os arquivos do projeto.
2. Coloque todos os arquivos na mesma pasta.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nenhuma biblioteca.

## 🎨 Personalização

Para trocar as cores, altere as variáveis
localizadas no início do arquivo `style.css`:

--brown
--dark
--cream
--beige
--light
--gold

As imagens utilizadas no projeto também podem ser
substituídas pelas suas próprias imagens.

## 📱 Responsividade

O site foi desenvolvido para funcionar em:

- Computadores
- Notebooks
- Tablets
- Celulares
